## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program copies `entry.png` (1024x1024, under 1 MiB) to `/output/entry.png` using only the Python standard library, with no network calls, so every run writes the same bytes.
